# Images and Fonts

It is advisable to store template image assets within your theme directory at:

```bash
src/assets/img/
```

<Callout type="info">
For optimal performance and organization, manage other images through the WordPress Media Library. To maintain a lightweight template, consider storing only SVG or minimal assets in your theme directory. This practice helps streamline the theme's loading speed and overall efficiency.
</Callout>
